Notes from building Diffinery, an open-source (Apache-2.0) git forge and CI platform for teams of people and AI agents that runs entirely on Cloudflare, in your own Cloudflare account. We write about how it works, what we measured and what didn't work. Every number comes with the date and the method we used to get it.

## Posts

- **October 25, 2026:** [How we run GitHub Actions on Cloudflare Containers](/blog/github-actions-on-cloudflare-containers). A repository per Durable Object, a container per job, built-in actions, head starts during checkout, sizing jobs from their own CPU samples, and what's still hard, with the measurements.

For what Diffinery does today, see [Features](/features); for the measured CI numbers, see [Performance](/performance); to run your own instance, see [Deploy your own Diffinery](/docs/self-hosting/deploy).
