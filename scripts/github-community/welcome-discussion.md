Welcome! Diffinery is an open-source GitHub and GitHub Actions alternative that runs on your own Cloudflare account.

**Where things go**
- **Q&A**: help deploying or running workflows. Include your workflow file and the job log if you can.
- **Ideas**: features you'd like. The [roadmap](https://github.com/codician-team/diffinery/blob/main/ROADMAP.md) lists the known gaps.
- **Show and tell**: your instance, your migration from GitHub, your agent setup.
- **Issues**: bugs, and workflows that run on GitHub but not on Diffinery. Security problems go to [the private report form](https://diffinery.com/security/report), never a public issue.

**Getting started**
- [Deploy your own](https://diffinery.com/docs/self-hosting/deploy)
- [Compatibility with GitHub Actions](https://diffinery.com/docs/actions/compatibility)
- [Contributing](https://github.com/codician-team/diffinery/blob/main/CONTRIBUTING.md)

Development happens on [diffinery.com/codician/diffinery](https://diffinery.com/codician/diffinery) and is mirrored here; pull requests are welcome in either place.
