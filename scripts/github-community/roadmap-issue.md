This issue tracks the main gaps people ask about. Nothing here has a date. Comment with what matters most to you, or 👍 an item below, and we'll split items into their own issues as work starts. The full list is in [ROADMAP.md](https://github.com/codician-team/diffinery/blob/main/ROADMAP.md).

- [ ] Hosted macOS, Windows and Arm runners (today: [self-hosted runners](https://diffinery.com/docs/actions/runners#self-hosted-runners))
- [ ] Git over SSH (today: HTTPS with a credential helper)
- [ ] Forks and pull requests between repositories
- [ ] Richer reviews: pending reviews, suggested changes, resolving threads
- [ ] Code-owner reviews and signed-commit requirements in branch protection
- [ ] Workflow events that are accepted but don't start runs yet, such as `issues` and `issue_comment`
- [ ] Importing from Gitea, Forgejo and GitLab
- [ ] Wikis, discussions and Pages-style static sites

**Good places to start contributing:** the gaps in [Compatibility with GitHub Actions](https://diffinery.com/docs/actions/compatibility), each with the GitHub behaviour to match, and issues labelled `good first issue`.
