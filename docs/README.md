# Diffinery documentation

The documentation is published at **[diffinery.com/docs](https://diffinery.com/docs)**. Its
source is Markdown in this repository, under
[`apps/diffinery/docs/`](../apps/diffinery/docs), and every page is also available as
Markdown at `https://diffinery.com/docs/<page>.md` and in
[llms.txt](https://diffinery.com/llms.txt) and [llms-full.txt](https://diffinery.com/llms-full.txt)
for AI assistants.
