# Getting help with Diffinery

- **How do I…?** Start with the [documentation](https://diffinery.com/docs) and the
  [FAQ](https://diffinery.com/faq). Every page is also Markdown, and
  [llms.txt](https://diffinery.com/llms.txt) lets an AI assistant read all of it.
- **Deploying your own instance:** [Deploy your own Diffinery](https://diffinery.com/docs/self-hosting/deploy),
  [Configuration](https://diffinery.com/docs/self-hosting/configuration) and the
  troubleshooting section of the deploy guide.
- **A workflow behaves differently from GitHub Actions:** check
  [Compatibility with GitHub Actions](https://diffinery.com/docs/actions/compatibility) first,
  then open an issue with the "Actions compatibility" template.
- **Bugs and feature requests:** open an issue on
  [GitHub](https://github.com/codician-team/diffinery/issues).
- **Security problems:** never in a public issue. See [SECURITY.md](SECURITY.md).

Diffinery is a volunteer-run open-source project with no paid support. There is no hosted
service: diffinery.com is the instance the project itself is developed on.
